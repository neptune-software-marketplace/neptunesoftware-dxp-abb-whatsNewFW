About
The What’s New Framework provides a powerful tool to notify users about updates, tasks, events, or news directly within a Launchpad or an application.

Key Features:

    • Notify users about changes or essential updates.

    • Use it across different applications or within your Launchpad.

How to Use:

1. Included Tiles:

The package contains a Tile Group with two tiles:

    • Configure App: Create keys to identify and group the messages you want to display. A single key can be associated with multiple messages.

    • WhatsNew App: Create and manage messages, assigning them to the appropriate keys.

2. Integration:

  • Add the provided code snippet to your app to display the “What’s New” messages to your users.
